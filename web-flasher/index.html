AirGradient to Omniscope

Install the custom I-9PSL firmware that sends one configurable HTTPS Workflow API request per minute—without AirGradient Cloud, MQTT, a local collector, or an inbound router port.

Before installing

  1. Use Chrome or Edge on a computer and a USB-C data cable.
  2. Close Android Studio, PlatformIO, Arduino IDE, and serial monitors.
  3. Disconnect the monitor, hold its recessed BOOT button, connect USB, then release BOOT.
  4. Click below and select USB JTAG / Serial Debug.
The installer can preserve your settings or erase the device. Start by preserving them. Erasing removes Wi-Fi and all monitor configuration. Do not disconnect USB while writing.
This installer requires desktop Chrome, Edge, or another Chromium browser with Web Serial support. Web Serial requires this page to be served over HTTPS or localhost.
